## 🚀 লোকালে চালানো (২ মিনিট)

```bash
npm install
cp .env.example .env        # তারপর .env ফাইলটা এডিট করুন
npm start
```

`.env`-এ যা লাগবেই:
| ভ্যারিয়েবল | কী দেবেন |
|---|---|
| `MONGODB_URI` | MongoDB Atlas-এর ফ্রি কানেকশন স্ট্রিং |
| `JWT_SECRET` | লম্বা র‍্যান্ডম টেক্সট |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | প্রথম বুটে এই দিয়ে **owner এডমিন অটো তৈরি হবে** (পাসওয়ার্ড ১০+ অক্ষর) |

তারপর ব্রাউজারে: `http://localhost:10000` (স্টোর) · `http://localhost:10000/#/admin` (এডমিন)

## ☁️ Render-এ ডিপ্লয়

1. এই ফোল্ডারটা GitHub-এ আপলোড করুন (ফাইল মাত্র ~১৫টা, এক টানেই হবে)
2. [render.com](https://render.com) → **New Web Service** → রিপো সিলেক্ট
3. Build: `npm install` · Start: `npm start` (render.yaml থাকায় অটো নেবে)
4. Environment-এ `MONGODB_URI`, `JWT_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` দিন
5. Deploy 🎉 — একটাই URL-এ স্টোর + এডমিন + API

## 🛠️ প্রথম দিন যা করবেন

1. `/#/admin` → লগইন → **Site Settings** → পেমেন্ট নাম্বার + WhatsApp বসান
2. **Products** → প্রোডাক্ট যোগ করুন (৩ কারেন্সির দাম দিন)
3. **Stock** → অ্যাকাউন্ট যোগ করুন (স্টক না থাকলে কাস্টমার কিনতে পারবে না)
4. চাইলে **Promo Codes**-এ একটা `WELCOME10` বানিয়ে ফেলুন 😉
